TAM-FNO Underwater Acoustic Prediction

A reproducible code release for time-adaptive Fourier neural operators that predict acoustic transmission loss from sound-speed profiles.

View Code Quick Start

What Is Included

TAM-FNO model FiLM-style temporal modulation on top of a 2D Fourier Neural Operator.
Temporal modulation Fourier time features drive FiLM-style channel modulation inside TAM-FNO.
Reproduction scripts Preprocessing, training, evaluation, and visualization entry points.
Clean release policy Data, checkpoints, logs, and generated experiment outputs are excluded.

Quick Start

conda env create -f environment.yml
conda activate tam_fno
pip install -e .

python scripts/preprocess_data.py \
  --raw-tl /path/to/TL.mat \
  --raw-ssp /path/to/SSP.mat

python src/scripts/train.py --epochs 100 --device cuda
python src/scripts/evaluate.py

Data Policy

The repository does not publish experimental data. Raw matrices, processed splits, normalizers, checkpoints, logs, and result archives remain local.

Expected raw file fields are square_TL in TL.mat and square_SSP in SSP.mat.

Repository

The repository keeps TAM-FNO core modules directly under src, minimal training and evaluation entry points under src/scripts, helper commands under scripts, and this static site under docs.
