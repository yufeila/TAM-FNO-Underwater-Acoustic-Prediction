# `src/tam_fno/scripts/` 脚本保留说明

这个目录只保留给复现者使用的最小入口脚本。

## 应保留

### `__init__.py`

必须保留。

它让 `scripts/` 成为 Python 子包，因此可以用下面的方式运行：

```bash
python -m tam_fno.scripts.train
```

### `train.py`

必须保留。

这是 TAM-FNO 的训练入口。复现者用它训练模型，并生成本地模型权重和基础训练输出。

### `evaluate.py`

建议保留。

这是最直接的 TAM-FNO 基础评估入口。复现者训练完模型后，可以用它确认模型能在测试集上正常推理并计算误差。

## 已移出仓库的脚本类型

以下脚本不再放在公开仓库中：

- 论文插图生成脚本
- 性能曲线绘制脚本
- 用于挑选论文展示样本的搜索脚本
- 图片标签、色条、版式后处理脚本
- 模型解释性可视化脚本

原因：这个仓库面向对论文感兴趣的复现者，公开代码应聚焦于 TAM-FNO 的训练和基础评估，不应包含论文写作过程中用于说明效果、修图或筛选展示样本的辅助脚本。

## 当前最小保留集合

```text
__init__.py
train.py
evaluate.py
```
