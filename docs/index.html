TAM-FNO Underwater Acoustic Prediction

Time-Adaptive Modulated Fourier Neural Operator for underwater acoustic transmission-loss prediction.

Yufei Yang
Code release and project page
Code Paper

TAM-FNO introduces temporal awareness into Fourier neural operators so that transmission-loss fields can be predicted under dynamic ocean conditions.

Abstract

Underwater acoustic field prediction is important for environment-aware sensing, communication, and autonomous underwater operations. Conventional numerical solvers can be accurate, but repeated simulation across many ocean states is computationally expensive.

TAM-FNO is a time-adaptive modulated Fourier Neural Operator for predicting acoustic transmission loss from sound-speed profiles. Instead of directly concatenating time to the spatial input, TAM-FNO separates spatial feature extraction from temporal conditioning. A temporal branch encodes the time index with multi-frequency Fourier features and modulates the FNO backbone through FiLM-style channel-wise scale and shift terms.

Introduction

Underwater acoustic field prediction supports tasks such as environment-aware sensing, underwater communication, and autonomous underwater vehicle planning. A conventional workflow repeatedly runs numerical acoustic solvers such as RAM under different ocean conditions. This is accurate but expensive when predictions are needed for many environmental states.

Fourier Neural Operators provide a fast surrogate route: once trained, they can map a sound-speed field to a transmission-loss field in a single forward pass. However, many existing FNO-based acoustic models mainly learn a spatial mapping and treat the ocean as nearly static.

Real ocean environments vary with daily and seasonal changes in temperature and salinity. Simply concatenating time to the input grid is not always effective, because the same global time descriptor is broadcast over all spatial locations. TAM-FNO addresses this by separating spatial feature extraction from temporal conditioning.

Problem Statement

Given a sound-speed profile and its associated time index, the goal is to predict the corresponding acoustic transmission-loss field over range and depth. The sound-speed profile describes the environmental state of the ocean, while the time index carries information about daily and seasonal variation.

In operator-learning terms, the task is to learn a time-parameterized mapping from sound-speed information to transmission loss. TAM-FNO treats time as a conditioning variable rather than simply appending it to the spatial input, so the model can adapt its prediction as the ocean state changes.

Method

TAM-FNO follows a dual-track design. The spatial branch processes the sound-speed field through a Fourier Neural Operator backbone, while the temporal branch transforms the raw time index into a periodic descriptor. The temporal descriptor generates modulation terms that adapt intermediate feature channels inside the FNO blocks.

The spatial branch receives the sound-speed field as a two-dimensional input over range and depth. A lifting layer maps this input to a latent tensor, and the backbone then propagates it through four TAM-FNO blocks. Each block combines spectral convolution, local residual mixing, and temporal modulation.

The temporal branch does not place time directly onto the spatial grid. Instead, it encodes the raw time index with multi-frequency Fourier features. In the implementation used in the paper, the descriptor contains daily and annual components, giving the model access to both diurnal and seasonal variation.

A small MLP turns the temporal descriptor into channel-wise scale and shift terms. These terms modulate the spatial feature channels as F_out = GELU(F_hat * (1 + gamma(t)) + beta(t)). This lets time steer the learned acoustic operator while keeping the spatial input pathway clean.

Experiments and Results

The experiments evaluate whether the learned surrogate can reproduce the spatial structure of transmission-loss fields. The selected visual comparison shows predicted TL fields and absolute error maps for the ground truth, baseline variants, and TAM-FNO.

The paper uses a real-world South China Sea sound-speed field dataset with 2920 samples over a full year, sampled 8 times per day. The corresponding transmission-loss labels are generated with the RAM acoustic solver. The dataset is split into 2336 training samples and 584 test samples using a fixed random seed.

TAM-FNO is compared with three variants that share the same FNO backbone: a static 2D-FNO baseline without temporal input, a scalar-time concatenation model, and a Fourier-encoding concatenation model. The evaluation reports RMSE, relative L2 error, SSIM, and Pearson correlation, covering both numerical error and spatial-structure fidelity.

TAM-FNO achieves the best reported value on all four metrics. Its RMSE is 1.9642 dB, compared with 2.3249 dB for the strongest non-FiLM baseline, which is about a 15.5% reduction.
